Setup checklist

Do them in this order. Changing a setting in Render redeploys the app (a minute or two); then reload this page and test again. Keep keys and tokens in Render only: never paste them into Kyro, an email or a chat.

1. Phone calls (nothing new to set up)
  1. In Render, open the nexus-genesis-certified service, then Environment. Check these are set: PHONE_PROVIDER=twilio, PUBLIC_BASE_URL=https://nexus-genesis-certified.onrender.com, TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN, TWILIO_PHONE_NUMBER (a voice-capable Twilio number), PHONE_REALTIME_STREAMING_ENABLED=true.
  2. In the Twilio console, open that number. Under Voice, set A call comes in to a Webhook, HTTP POST, https://nexus-genesis-certified.onrender.com/api/voice/phone/incoming, and the status callback to …/api/voice/phone/call-status.
  3. In the Admin screen, open Phone numbers for Kyro and add your own mobile number, linked to your own account. Only listed numbers are answered as themselves. A number that is not listed is told politely it is not authorized and the call ends; it only rings you if you have turned on PHONE_SCREENING_ENABLED.
  4. To let Kyro place calls, also set NEXUS_CALLS_ENABLED=true.
  5. Use Send myself a test on the Phone calls card: your phone should ring and speak a short message. Then phone Kyro's number from your listed phone. Never test by dialling from a phone that is not on the list.

A Twilio trial account can only call numbers you have verified in the Twilio console.

2. Email (about 30 minutes)
  1. Create a SendGrid account and an API key with the Mail Send permission (Resend works too: use NEXUS_EMAIL_PROVIDER=resend and RESEND_API_KEY).
  2. In SendGrid open Settings, Sender Authentication. Fastest start: Verify a Single Sender with an address you control and click the link SendGrid emails you. Before real users, choose Authenticate Your Domain instead (you add a few DNS records) so mail is not treated as spam.
  3. In Render set: NEXUS_EMAIL_ENABLED=true, NEXUS_EMAIL_PROVIDER=sendgrid, SENDGRID_API_KEY, and NEXUS_EMAIL_FROM = the exact verified address. Kyro reads NEXUS_EMAIL_FROM for the sender; SENDGRID_FROM_EMAIL is not used.
  4. Use Send myself a test on the Email card. It goes to your account's own email. Check the inbox and the spam folder.

Kyro only sends an email after the person confirms it, and cannot read email.

3. WhatsApp (sandbox first, business approval in parallel)
  1. In the Twilio console open Messaging, Try it out, Send a WhatsApp message. Note the sandbox number and your join code.
  2. On your phone, open WhatsApp and send join your-code to the sandbox number. Only phones that did this can receive sandbox messages.
  3. In Render set NEXUS_WHATSAPP_ENABLED=true and TWILIO_WHATSAPP_FROM=whatsapp:+14155238886 (use the sandbox number Twilio shows).
  4. Use Send myself a test on the WhatsApp card.
  5. For real users, start this now because it takes days: in Twilio open Messaging, Senders, WhatsApp senders, register your business number and complete Meta's business verification. Then register message templates (a reminder, an alert, an appointment notice): outside a 24-hour window after a person messages you, WhatsApp only allows approved templates. Finally change TWILIO_WHATSAPP_FROM to your approved number.
4. Text messages (do last)
  1. In Twilio open Messaging, Settings, Geo permissions and enable every country you will text (otherwise error 21408).
  2. Make sure the sending number is accepted by the carriers in each country. This is what error 30032 means: the number is not registered for texting. A toll-free number needs toll-free verification; some countries need a registered sender ID or a local number. Twilio's regulatory guidelines page for each country says which.
  3. In Render set NEXUS_SMS_ENABLED=true (or NEXUS_MESSAGES_ENABLED=true for all channels) and TWILIO_FROM_NUMBER (or TWILIO_PHONE_NUMBER) to the sender.
  4. Use Send myself a test on the Text messages card. It waits a moment and then reports what the phone network said, not just that Twilio accepted it.

If a test fails

The test result names the cause in plain words. The common ones:

  • 30032 the sending number is not registered for texting. Complete verification or registration in Twilio, or send from a registered number.
  • 21408 country not enabled. Turn it on under Geo permissions.
  • 21608 trial account: verify the recipient in Twilio, or upgrade.
  • 63015 / 63007 / 63016 WhatsApp: join the sandbox, set a real WhatsApp sender, or use an approved template.
  • Email 403 the sender address is not verified with the email provider.
  • 20003 / email 401 the account details or API key in Render are wrong.
